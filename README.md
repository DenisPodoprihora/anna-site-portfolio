# Anna Zhdankina — portfolio

Одностраничный сайт-портфолио UX/UI & product designer. Свёрстан по макету Figma
(десктоп 1440px).

## Стек

Чистый HTML / CSS / JS — без сборки, npm и зависимостей.

## Структура

```
index.html              разметка
assets/css/style.css    стили
assets/js/main.js       переключение языка EN/RU
assets/fonts/           DM Sans (variable, woff2)
assets/icons/           svg-иконки и фавикон
assets/img/             фотографии проектов и портрет
content/content.json    все тексты сайта парами en/ru
content/content.md      те же тексты в читаемом виде — для перевода
```

## Тексты и языки

Все тексты вынесены в `content/content.json` в виде пар `{ "en": "...", "ru": "..." }`.
Разметка хранит английский текст как fallback, поэтому страница остаётся
рабочей, даже если словарь не загрузился.

Язык выбирается в порядке: параметр `?lang=ru` → сохранённый выбор в
`localStorage` → язык браузера → английский.

## Локальный запуск

`content.json` подгружается через `fetch`, поэтому нужен http-сервер
(при открытии файла напрямую браузер блокирует запрос и сайт показывается
только на английском):

```bash
python3 -m http.server 8777
```

Затем открыть http://localhost:8777/

## Шрифты

В макете заголовок hero набран Aeonik Pro Medium, а заголовок контакта —
Proxima Nova Semibold. Оба шрифта платные и в проект не входят, поэтому
подставлен DM Sans с сохранением размеров, трекинга и `opsz` из Figma.
