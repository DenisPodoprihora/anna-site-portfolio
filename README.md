# Anna Zhdankina — portfolio

Одностраничный сайт-портфолио UX/UI & product designer.

## Стек

Чистый HTML / CSS / JS — без сборки, npm и зависимостей.

## Структура

```
index.html              разметка
assets/css/style.css    стили
assets/js/main.js       переключение языка EN/RU
assets/fonts/           DM Sans (variable, woff2)
assets/icons/           svg-иконки и фавикон
assets/img/             фотографии проектов и портрет
content/content.json    все тексты сайта парами en/ru
```

## Тексты и языки

Все тексты вынесены в `content/content.json` в виде пар `{ "en": "...", "ru": "..." }`.

По умолчанию сайт всегда английский. Язык браузера не учитывается:
русская версия ещё не вычитана, поэтому на неё нельзя попасть случайно.

Русскую можно посмотреть только явно — `index.html?lang=ru`.

Переключатель языка и запоминание выбора появятся позже; тогда же вернётся
и определение языка браузера.

## Ссылки

CV лежит на Google Drive и скачивается сразу, без страницы просмотра — ссылка
вида `drive.google.com/uc?export=download&id=...`. Она одна и та же в шапке
(«Download CV») и в нижней карточке контактов; правится в двух местах
`index.html`.

Картинка проекта и кнопка «View project» ведут в одно место и открываются в
новой вкладке: клик по картинке делает то же, что клик по кнопке. Поэтому у
каждой из шести карточек с кнопкой URL продублирован — в `.project__cta` и в
`a.project__media`; правится тоже в двух местах. У карточки 03 «Coming soon»
кнопки нет, картинка осталась `<div>` без ссылки и без ховера.

Шесть карточек в блоке Explorations пока ведут на `#` — ссылок на кейсы нет.

## Масштабирование

Макет нарисован на 1440px и на этой ширине воспроизводится один в один.
Ниже 1440 страница **не перестраивается, а сжимается целиком**: правило
`zoom` в `body` умножает разом кегли, отступы, поля, зазоры, картинки и
размеры компонентов, поэтому сетка, выравнивание и позиции остаются
макетными — просто меньше.

Коэффициент (`viewport / 1440`, не больше 1) считает скрипт в `<head>` и
кладёт в переменную `--fit`. Он стоит именно в `<head>`, чтобы значение
успело примениться до первой отрисовки, иначе страница мигнёт
немасштабированной.

Скрипт берёт `documentElement.clientWidth`, а не `innerWidth`: `clientWidth`
не включает ширину полосы прокрутки. С `innerWidth` на системах с
классическими скроллбарами макет вылезал бы по горизонтали ровно на её
ширину.

`body` имеет жёсткую `width: 1440px`, потому что `zoom` не сужает элемент с
`width: 100%` — тот растянулся бы на 1440px в системе координат страницы, и
после сжатия справа осталась бы пустая полоса. По той же причине
`margin: 0 auto` — на широких окнах макет центрируется, как и раньше.

На мобильных дополнительно работает `<meta name="viewport" content="width=1440">`:
там браузер сам показывает макет целиком, поэтому `--fit` остаётся равен 1 и
двойного масштабирования не происходит.

Проверено: при 1440px страница побитово совпадает с макетом, на 1280 и 1024
горизонтальной прокрутки нет, а все элементы уменьшаются ровно в
1440/ширина окна раз по обеим осям.
